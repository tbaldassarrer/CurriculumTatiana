# Curriculum Tatiana Baldassarre

Curriculum web personal de Tatiana Baldassarre, desarrollado con HTML y CSS.

## Contenido

- `index.html`: estructura del curriculum.
- `styles.css`: estilos responsive y estilos de impresion.
- `fotoTati.png`: imagen de perfil utilizada en la pagina.

## Como verlo

Abre `index.html` directamente en el navegador.

## Tecnologias

- HTML5
- CSS3
- Diseno responsive

## APIs y recursos externos

- Devicon CDN via jsDelivr: iconos de tecnologias y herramientas.
- Unsplash Images: imagenes decorativas para las tarjetas de proyectos.
